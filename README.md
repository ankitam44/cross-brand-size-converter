# Cross-brand size converter

Enter the brand + size you already know, pick a brand you don't, and get an honest
converted size — with a confidence label and a one-line reason it might be off. No
signup, no account: your size is saved to this browser only.

## Run locally

    npm install
    npm run dev

## Deploy to a free tier (Netlify)

    npm run build
    npx netlify deploy --prod --dir=dist

## Tests

    npm test
